Lighting Manager is a Fast and lightweight mod manager for Minecraft. This isn't a client, but rather an application that is dependent on the Minecraft Launcher and is used to easily manage Minecraft Launcher and how you would manually install Minecraft Mods for Minecraft: Java Edition. 

## What this application offers

* Easy management of Minecraft profiles and mods for the official Minecraft Launcher
* Allows you to easily backup your mods and assess them manually without third-party clients
* Allows direct launching of Minecraft profiles without need of running Minecraft Launcher Directly (This requires you to already have a vanilla or modded profile installed from the Minecraft Launcher. No company likes piracy >:(    )
